# Sprite reference images

Drop the reference image here as `reference.png`. It's used by the 24×24 sprite redesign
task in `PRD.md` as the visual target for chibi-style pixel art.

The reference shows 8 critters (cat, dog, hamster, bird/parrot, rabbit, fox, frog, turtle)
in a chibi pixel art style with bold outlines, white bellies/chests, expressive faces, and
subtle ground shadows.

When iterating on sprites, read this image to stay aligned with the target style.
